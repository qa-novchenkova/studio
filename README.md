# Студия — витрина маркетинг-контента

Портфолио-сайт о создании маркетингового контента с погружением в отрасль:
презентации, лид-магниты и интерактив. Второй проект в дополнение к кампании «Пульс».

**Живой сайт:** https://qa-novchenkova.github.io/studio/

> Демо-проект портфолио. Контент создан через ИИ-инструменты с ручной доработкой.

## Что внутри

**6 кейсов по нишам** — у каждого своя тема, палитра, шрифты и графика:

| Ниша | Презентация | Стилистика |
|------|-------------|------------|
| Сельское хозяйство | «Поле недобирает» | Georgia, полоса-поле, фазы культуры |
| Кафе и рестораны | «Меню, которое продаёт» | Bookman, меню-верстка с отточиями |
| Корма для животных | «Миска, к которой возвращаются» | Century Schoolbook, сплит-экран, теги |
| Автосервис | «Запись без хаоса» | Arial + Cambria, гигантский шрифт, донат |
| Недвижимость | «Ключи находят хозяина» | Times + Courier, архитектурный чертёж |
| Электроника | «Карточка, которая продаёт» | Courier, «спека», циан и маджента |

- **Лид-магниты** — 6 чек-листов и гайдов в PDF (A4, готовы к печати).
- **Интерактив** — тест, калькулятор и три мини-игры со своей графикой.
- **Баннеры** — 11 макетов в трёх форматах (пост, веб-баннер, сторис).
- **Подход** — как рождается материал: погружение → смысл → визуал → доводка.
- **Контакты** — форма с валидацией.

## Принцип: каждая презентация уникальна

Не шаблон с подменой текста. Для каждой ниши — своя тема из реальной боли отрасли,
своя палитра и **свои иллюстрации**. Для агро нарисовано 9 оригинальных SVG:
поле в перспективе, сравнение колосьев, фазы развития, карта зон поля,
таймлайн программы сезона, угрозы урожаю, календарь-дуга, снопы, трактор в поле.

## Технологии

React 19 · TypeScript · Vite · Tailwind CSS 4 · GitHub Pages (автодеплой).
Зелёная редакционная айдентика: сериф Georgia в заголовках, акцент `#2E7D4F`, золото `#D89A1E`.
Тёмная и светлая темы. Первый экран — анимированная SVG-сцена
(`src/components/AgroScene.tsx`): солнце с лучами, борозды поля, растущие ростки,
качающиеся колосья, парящая пыльца. Анимации отключаются при `prefers-reduced-motion`.

## Как устроены ассеты

- `public/decks/agro.pptx` — презентация (собирается скриптом на `pptxgenjs`,
  иллюстрации вставляются как PNG, отрендеренные из SVG через `sharp`).
- `public/illustrations/*.svg` — исходные векторные иллюстрации.
- `public/previews/*.png` — титульный слайд и галерея (рендер через LibreOffice + PyMuPDF).

Контент карточек и статусы — в `src/data.ts`.

## Запуск и деплой

```bash
npm install
npm run dev      # локальный сервер
npm run build    # сборка в dist/
```

Деплой автоматический: `git push` в `main` → GitHub Actions → GitHub Pages.
